# 中国日历·精简版

一条干净的中国日历订阅：**法定放假/补班 + 传统节日 + 二十四节气**。

## 设计原则

- **法定节假日不预测**：只录入国务院办公厅已经正式发布的年度放假调休通知。
- **显示第几天**：例如 `国庆节 假期 第3天/共7天`、`国庆节 补班 第2天/共2天`。
- **传统节日保留**：春节、除夕、元宵、龙抬头、端午、七夕、中元、中秋、重阳、腊八、清明等。
- **二十四节气保留**：清明与“清明节”合并，避免同一天出现两条近义事件。
- **自动去重**：春节、清明、端午、中秋等遇到法定假期时，不再额外生成同名传统节日事件。
- **不阻塞时间**：所有事件均为全天、透明状态，不占用忙闲时间。

## 数据准确性

法定放假/补班的权威源仅为中国政府网发布的国务院办公厅通知：

- 2025：国办发明电〔2024〕12号
- 2026：国办发明电〔2025〕7号

农历与二十四节气由 `lunar_python==1.4.8` 计算，并用香港天文台的《公历与农历日期对照表》和年历做基准校验。CI 中固定校验 2026 年全部 24 个节气日期及关键农历节日日期。

**如果下一年度国务院通知尚未录入，本项目宁可暂不显示该年度法定调休，也不会根据惯例猜日期。** 传统节日和二十四节气仍会正常生成。

## 订阅

Apple Calendar / Across 等支持 URL 订阅的客户端可使用：

`https://raw.githubusercontent.com/schweify/china-calendar-clean/main/dist/china-calendar.ics`

建议刷新频率：每天。

## 维护

GitHub Actions 每周重新生成、运行校验；生成结果发生变化时自动提交。每年进入 11 月后，如下一年度国务院法定节假日数据尚未录入，维护工作流会创建提醒 Issue。

## 范围

默认生成 `当前年份 - 1` 到 `当前年份 + 9` 的传统节日和节气；法定节假日只输出仓库中已有国务院正式通知的数据年份。
